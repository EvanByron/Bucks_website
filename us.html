Project Info
The goal of this project is to create a website rebrand for the Milwaukee Bucks. I wanted to build a website that was very user friendly and had a fresh and cohesive feel. I also wanted to build a site that was very user friendly.
Site Description
The site features simple and straightforward options to keep up with the Milwaukee Bucks. You are able to watch highlights, purchase tickets, check standings, keep up with injuries and keep up with the teams stats. The main users we are looking to target are everyday fans looking to keep up with their favorite team in a simple way.
About the Author
